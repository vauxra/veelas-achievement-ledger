# AI Declaration

This project used AI assistance beyond basic autocomplete.

## Disclosure level

**Copilot** — AI implemented portions of the plugin while the human developer provided direction, testing feedback, constraints, and review. The human developer remained responsible for deciding what to build, validating behavior in game, and accepting or rejecting changes.

This level follows the terminology referenced by the Dalamud AI Usage Policy for official plugin repository submissions.

## What AI helped with

- Drafting C# implementation changes.
- Inspecting local Dalamud/ClientStructs/Lumina API surfaces.
- Adding diagnostic instrumentation.
- Writing tests and verification scripts.
- Drafting documentation and research notes.
- Running build, policy, and security checks.

## Human review and testing

The plugin was tested with human-run in-game scenarios including:

- opening the tracker/config UI,
- manual achievement progress refresh,
- native Achievement window browsing,
- achievement completion observation,
- mining/gathering activity observation.

AI-generated code was not accepted blindly. Changes were built, tested, scanned, and reviewed against Dalamud policy constraints before commit.

## Assets

No AI-generated user-facing icons, images, music, sounds, or textures are included.
